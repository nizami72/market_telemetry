# Правила обучения моделей (Training Rules v1.0)

## 1. Общие принципы

* Каждая модель обучается **независимо**.
* Каждая модель отвечает только за **один временной горизонт**.
* Все модели используют **одинаковый набор признаков**, но разные лейблы.
* Обучение происходит **один раз в сутки**.

---

## 2. Скользящее окно обучения

Для обучения всегда используется только **последние 30 календарных дней**.

Каждый день окно сдвигается:

* добавляются данные последних суток;
* удаляются самые старые сутки;
* весь процесс обучения выполняется заново.

---

## 3. Независимые модели

| Модель | Горизонт |
| ------ | -------: |
| M15    | 15 минут |
| M30    | 30 минут |
| M45    | 45 минут |
| M60    | 60 минут |

Каждая модель имеет:

* собственный TP;
* собственный Label Store;
* собственный файл модели;
* собственный файл метаданных.

---

## 4. Автоматический подбор TP

Перед генерацией лейблов для каждой модели отдельно:

1. анализируется статистика последних 30 дней;
2. рассчитывается оптимальное значение TP;
3. TP фиксируется на весь цикл обучения данной модели;
4. TP сохраняется в соответствующем `meta.json`.

На этапе v1:

```text
TP = SL
```

---

## 5. Генерация лейблов

После определения TP:

* создаются лейблы только для соответствующего горизонта;
* используется алгоритм LONG / SHORT / FLAT / UNKNOWN;
* записи с `UNKNOWN` исключаются из обучения.

---

## 6. Формирование обучающего датасета

Обучающий датасет строится объединением:

```text
Feature Store
        +
Label Store
```

по полю

```text
timestamp
```

После объединения:

* строки с `UNKNOWN` удаляются;
* остальные используются без изменения признаков.

---

## 7. Признаки (Features)

Во всех моделях используется один и тот же набор признаков.

Состав признаков должен быть одинаковым как при обучении, так и при реальной торговле.

---

## 8. Временная последовательность

Перемешивание данных запрещено.

Используется только хронологический порядок.

Любое нарушение временной последовательности считается ошибкой.

---

## 9. Валидация

Используется только Time Series Validation.

Запрещается:

* Random Split;
* Shuffle;
* случайное разбиение выборки.

---

## 10. Финальное обучение

После завершения валидации:

* модель обучается повторно на всей обучающей выборке;
* используется найденное количество деревьев (или иные оптимальные параметры);
* модель сохраняется в каталог `models`.

---

## 11. Сохранение результатов

Для каждой модели сохраняются:

* файл модели;
* файл метаданных;
* параметры обучения;
* используемый TP;
* дата обучения;
* статистика качества модели.

---

## 12. Независимость моделей

Модели не используют результаты друг друга.

Каждая модель:

* обучается самостоятельно;
* делает прогноз самостоятельно;
* может быть переобучена независимо от остальных.

---

## 13. Неизменность Feature Store

Во время обучения запрещается изменять Feature Store.

Все изменения должны происходить только через:

* генерацию новых лейблов;
* изменение параметров обучения;
* изменение конфигурации модели.

---

## 14. Воспроизводимость

Каждое обучение должно быть полностью воспроизводимым.

Для этого должны сохраняться:

* дата обучения;
* период данных;
* TP;
* SL;
* горизонт модели;
* версия генератора лейблов;
* версия Feature Store;
* версия обучающего скрипта.
