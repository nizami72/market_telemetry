Алгоритм Label Generator v1.0
### Алгоритм Label Generator v1.0

**Назначение**

Сгенерировать обучающие лейблы (`LONG`, `SHORT`, `FLAT`, `UNKNOWN`) для каждой записи Feature Store на основе заданного горизонта прогнозирования и значений TP/SL.

---

## Входные параметры

* Feature Store (OHLC + признаки)
* `horizon_rows` — количество 10-секундных свечей в горизонте

    * M15 = 90
    * M30 = 180
    * M45 = 270
    * M60 = 360
* `TP`
* `SL` *(на текущем этапе TP = SL)*

---

## Выходные данные

Для каждой строки формируется запись:

| Поле           | Описание                                                          |
| -------------- | ----------------------------------------------------------------- |
| timestamp      | Время входа                                                       |
| label          | 0=FLAT, 1=LONG, 2=SHORT, 3=UNKNOWN                                |
| hit_after_rows | Через сколько свечей была достигнута цель (-1 для FLAT и UNKNOWN) |

---

# Алгоритм

Для каждой строки `i` Feature Store:

### Шаг 1

Определить цену входа

```text
EntryPrice = Open[i]
```

---

### Шаг 2

Вычислить уровни целей

```text
LONG_LEVEL  = EntryPrice + TP

SHORT_LEVEL = EntryPrice - SL
```

---

### Шаг 3

Начать просмотр **со следующей свечи**

```text
j = i + 1
```

Текущая свеча не анализируется.

Это исключает использование информации, неизвестной в момент открытия сделки (look-ahead bias).

---

### Шаг 4

Последовательно просмотреть свечи

```text
j = i+1 ... i+horizon_rows
```

Для каждой свечи выполнить проверки в следующем порядке.

---

## Случай 1

Если одновременно

```text
High[j] >= LONG_LEVEL

и

Low[j] <= SHORT_LEVEL
```

то

```text
label = UNKNOWN

hit_after_rows = -1
```

Запись считается неоднозначной.

Просмотр прекращается.

---

## Случай 2

Если

```text
High[j] >= LONG_LEVEL
```

то

```text
label = LONG

hit_after_rows = j - i
```

Просмотр прекращается.

---

## Случай 3

Если

```text
Low[j] <= SHORT_LEVEL
```

то

```text
label = SHORT

hit_after_rows = j - i
```

Просмотр прекращается.

---

### Шаг 5

Если просмотрено всё окно

```text
i+1 ... i+horizon_rows
```

и ни одно условие не выполнилось

то

```text
label = FLAT

hit_after_rows = -1
```

---

# Кодировка классов

| Код | Класс   |
| --: | ------- |
|   0 | FLAT    |
|   1 | LONG    |
|   2 | SHORT   |
|   3 | UNKNOWN |

---

# Особенности алгоритма

* Цена входа всегда берется из **Open** текущей свечи.
* Анализ начинается **со следующей свечи**.
* Используются только значения **High** и **Low**.
* После первого найденного события просмотр прекращается.
* `UNKNOWN` не используется при обучении модели.
* Для `FLAT` и `UNKNOWN` значение `hit_after_rows = -1`.
* Генерация выполняется независимо для каждого горизонта (M15, M30, M45, M60).
