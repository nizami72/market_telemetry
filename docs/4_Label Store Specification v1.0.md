# Label Store Specification v1.0

## Назначение

Label Store содержит результаты разметки данных для каждого временного горизонта модели.

Каждый горизонт имеет собственный файл:

```text
labels/
    m15.parquet
    m30.parquet
    m45.parquet
    m60.parquet
```

Feature Store не содержит лейблов. Label Store хранится отдельно и может быть полностью пересоздан в любой момент без изменения исходных рыночных данных.

---

# Формат файла

Каждый файл содержит следующие поля:

| Поле           | Тип      | Описание                                                                                   |
| -------------- | -------- | ------------------------------------------------------------------------------------------ |
| timestamp      | datetime | Временная метка строки из Feature Store. Используется для объединения (JOIN) с признаками. |
| label          | uint8    | Класс, присвоенный данной записи.                                                          |
| hit_after_rows | int16    | Количество 10-секундных свечей до достижения TP. Для FLAT и UNKNOWN равно -1.              |

---

# Кодировка классов

| Код | Класс   | Описание                                                                                                                             |
| --: | ------- | ------------------------------------------------------------------------------------------------------------------------------------ |
|   0 | FLAT    | За весь горизонт ни LONG TP, ни SHORT TP не были достигнуты.                                                                         |
|   1 | LONG    | LONG TP был достигнут раньше SHORT TP.                                                                                               |
|   2 | SHORT   | SHORT TP был достигнут раньше LONG TP.                                                                                               |
|   3 | UNKNOWN | LONG TP и SHORT TP были достигнуты внутри одной и той же свечи. Порядок определить невозможно. Такие записи исключаются из обучения. |

---

# Поле hit_after_rows

Показывает, через сколько 10-секундных свечей после открытия сделки был достигнут TP.

Примеры:

| Значение | Интерпретация                                 |
| -------: | --------------------------------------------- |
|        1 | TP достигнут через первую свечу после входа.  |
|       18 | TP достигнут через 180 секунд (3 минуты).     |
|       42 | TP достигнут через 420 секунд (7 минут).      |
|       -1 | TP не достигнут (FLAT) либо ситуация UNKNOWN. |

---

# Пример содержимого m15.parquet

| timestamp            | label | hit_after_rows |
| -------------------- | ----: | -------------: |
| 2026-07-12T12:09:11Z |     1 |             23 |
| 2026-07-12T12:09:21Z |     0 |             -1 |
| 2026-07-12T12:09:31Z |     2 |             41 |
| 2026-07-12T12:09:41Z |     3 |             -1 |

---

# Использование

Во время подготовки обучающего датасета выполняется объединение:

```text
Feature Store
        +
Label Store
        ↓
Training Dataset
```

по полю:

```text
timestamp
```

Записи с классом `UNKNOWN` исключаются до начала обучения модели.
