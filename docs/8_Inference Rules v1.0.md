# Правила инференса (Inference Rules v1.0)

## 1. Общая идея

Инференс выполняется независимо для каждой модели каскада:

* M15
* M30
* M45
* M60

Каждая модель работает только со своим горизонтом времени и была обучена с собственными параметрами TP/SL.

---

## 2. Подготовка данных

Перед каждым запуском модели необходимо:

1. Получить последние рыночные данные.
2. Построить полный набор признаков (Feature Vector), идентичный тому, который использовался при обучении.
3. Проверить отсутствие пропусков и корректность порядка признаков.

Набор признаков должен **полностью совпадать** с обучающим.

---

## 3. Загрузка модели

Для каждой модели загружается:

* `lgbm_m15.pkl`
* `lgbm_m30.pkl`
* `lgbm_m45.pkl`
* `lgbm_m60.pkl`

Одновременно загружается соответствующий файл метаданных:

* `m15_meta.json`
* `m30_meta.json`
* ...

Из него извлекаются:

* TP
* SL
* горизонт
* версия модели
* дата обучения

Это гарантирует, что торговая логика использует те же параметры, с которыми модель была обучена.

---

## 4. Получение вероятностей

Каждая модель возвращает вероятности трех классов:

```text
P(FLAT)
P(LONG)
P(SHORT)
```

Например

```text
FLAT  = 0.18
LONG  = 0.61
SHORT = 0.21
```

---

## 5. Принятие решения

Используется только наиболее вероятное направление.

Например

```text
LONG = 0.61
```

Если

```text
LONG >= DecisionThreshold
```

открывается LONG.

Если

```text
SHORT >= DecisionThreshold
```

открывается SHORT.

Иначе

```text
ничего не делать.
```

---

## 6. Постановка ордеров

После открытия позиции немедленно выставляются биржевые ордера:

Для LONG

```text
TP = EntryPrice + TP
SL = EntryPrice - SL
```

Для SHORT

```text
TP = EntryPrice - TP
SL = EntryPrice + SL
```

TP и SL должны быть размещены на стороне биржи сразу после открытия позиции.

---

## 7. Управление сделкой

После установки TP и SL

модель больше не участвует в сопровождении сделки.

Закрытие происходит исключительно:

* по TP;
* по SL;
* либо по дополнительным правилам торговой системы (если они будут добавлены в следующих версиях).

---

## 8. Независимость моделей

Каждая модель принимает решение независимо.

Например

```text
M15  -> LONG (0.73)

M30  -> FLAT (0.48)

M45  -> LONG (0.55)

M60  -> SHORT (0.51)
```

Инференс заканчивается на этапе получения этих вероятностей.

Правила объединения решений нескольких моделей (голосование, фильтрация, каскад и т.п.) являются отдельным модулем торговой системы и не входят в правила инференса.

---

## 9. Запрет на изменение параметров

Во время инференса запрещается изменять:

* TP;
* SL;
* горизонт модели;
* набор признаков;
* порядок признаков.

Инференс всегда должен использовать параметры, сохраненные вместе с моделью во время обучения.

---

## 10. Логирование

Для каждой оценки рекомендуется сохранять:

* время оценки;
* модель (M15/M30/M45/M60);
* вероятность LONG;
* вероятность SHORT;
* вероятность FLAT;
* принятое решение;
* TP и SL, использованные для расчета;
* цену входа (если сделка открыта).

Это позволит впоследствии сравнивать прогнозы модели с фактическим поведением рынка и анализировать качество работы системы.
